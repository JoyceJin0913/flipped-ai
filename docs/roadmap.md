# 心动小屋 v0.2 工作框架

> 记录 v0.2 从「硬编码 Demo」到「AI 驱动恋综世界」的完整落地路径。
> 更新时间：2026-08-14

---

## 一、现状 vs 终点

```
现在（v0.1）                        终点（v0.2 MVP）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
硬编码 3 个场景                 →   LLM 动态生成 N 个场景
温宁说啥都是写死的字符串         →   温宁真的能记住/回应你说过的话
选 A/B/C 后果固定                →   选择进入世界状态，影响之后剧情
关掉 App 世界停止                →   即使不在线，明早回来发现有事发生
10 个人只有名字+位置             →   每个人有独立人设+记忆+情绪
```

## 二、四层架构（依赖关系从下到上）

```
┌─────────────────────────────────────────┐
│  第 4 层：世界层（World）                │  ← 最后做
│  事件调度 · 定时任务 · 你不在时发生的事    │
├─────────────────────────────────────────┤
│  第 3 层：故事层（Story）                │
│  Scene 生成 · Choice 判定 · 关系更新     │
├─────────────────────────────────────────┤
│  第 2 层：角色层（Character）            │
│  人设卡 · 三层记忆 · 单个 Agent          │
├─────────────────────────────────────────┤
│  第 1 层：基础设施（Infra）              │  ← 现在从这里开始
│  LLM 调用封装 · 存储 · 前后端骨架         │
└─────────────────────────────────────────┘
```

## 三、5 个里程碑

### 🏗️ 里程碑 1：跑通「跟一个人聊天」

**目标**：你能在网页上真的跟温宁对话，她能记住你说过什么。
**产品验证点**：单人 AI 陪伴是否有沉浸感。

| # | 任务 | 属于哪一层 | 产出 |
|---|---|---|---|
| 1.1 | LLM 调用封装 `lib/llm.ts` | 基础设施 | 一个 `chat()` 函数，关思考、切换 provider、错误处理都做好 |
| 1.2 | 建 `backend/` 目录 + Node/Bun 服务 | 基础设施 | 前端能通过 `/api/chat` 请求后端，后端再调豆包（保护 API key） |
| 1.3 | 温宁人设卡（单人 v1） | 角色层 | JSON 文件描述温宁的性格、背景、说话风格 |
| 1.4 | 短期记忆（一次对话内） | 角色层 | 一次会话内温宁记得 5 分钟前你说的话 |
| 1.5 | 前端 UI：跟温宁聊天页 | 故事层 | 一个简单 chat 界面（复用现有 `chatTopics` UI） |

**验证**：能连续跟温宁聊 10 轮，她不出戏、不忘记开头。

---

### 🎭 里程碑 2：跑通「Scene → Choice → 后果」

**目标**：厨房那 12 分钟场景变成 LLM 实时生成 + 你的选择真的影响后续。
**产品验证点**：核心 loop（看到 → 选择 → 后果）是否成立。

| # | 任务 | 属于哪一层 | 产出 |
|---|---|---|---|
| 2.1 | 长期记忆（跨会话） | 角色层 | 你 Day 1 说"喜欢下雨"，Day 5 温宁能提起 |
| 2.2 | Scene 生成器 | 故事层 | 给定角色+场景+当前关系，LLM 生成对话+3 个选项 |
| 2.3 | Choice 判定器 | 故事层 | 你选 A 之后，LLM 生成后果 + 更新关系数值 |
| 2.4 | 世界状态存储（简易版） | 基础设施 | SQLite 或 JSON 文件，记录关系值、事件历史 |
| 2.5 | 替换厨房场景 | 前端 | 把 `house.ts` 里硬编码的厨房场景换成 API 调用 |

**验证**：同样的厨房场景玩 3 遍，每次因为选择不同得到不同后果。

---

### 👥 里程碑 3：多人 + 关系网

**目标**：10 个角色都能各自扮演，且互相之间有关系。
**产品验证点**：Information Gap（AI 知道但你不知道）是否成立。

| # | 任务 | 属于哪一层 | 产出 |
|---|---|---|---|
| 3.1 | 10 个角色的人设卡 | 角色层 | 每个人独立人格、职业、说话风格 |
| 3.2 | 角色间关系图初始化 | 故事层 | 沈知 → 温宁：暧昧；林一 → 温宁：喜欢 |
| 3.3 | Truth Layer / User Layer 分离 | 故事层 | AI 知道全部关系，前端只显示你观察到的 |
| 3.4 | 「心动观察」Tab 动态化 | 前端 | Tab 2 显示的关系值来自后端而非硬编码 |

**验证**：温宁跟你说的话，跟她跟沈知说的话，风格上有明显差异。

---

### 🌍 里程碑 4：世界持续运行

**目标**：关掉 App 一晚上，第二天回来发现「23:41 沈知和温宁在厨房聊了 18 分钟」。
**产品验证点**：这是心动小屋区别于普通 AI Chat 的**核心差异化**。

| # | 任务 | 属于哪一层 | 产出 |
|---|---|---|---|
| 4.1 | 事件调度器 | 世界层 | 定时任务，每 X 小时角色间自动发生一件事 |
| 4.2 | 「镜头」Tab | 前端 | 展示"你错过的瞬间" |
| 4.3 | 心动消息推送 | 世界层 | 剧情推进器（例：匿名消息） |
| 4.4 | Day 循环 + 天数推进 | 故事层 | Day 4 → Day 5，故事时间线继续走 |

**验证**：早上打开 App，看到 3 条昨晚发生的事，产生「我不在时也发生了什么」的感觉。

---

### 🎬 里程碑 5：Season 结局

**目标**：跑完 7 天，生成"我的 Season 01"。
**产品验证点**：完整故事闭环 + UGC 内容雏形。

| # | 任务 | 属于哪一层 | 产出 |
|---|---|---|---|
| 5.1 | 最终选择系统 | 故事层 | Day 7 你选择跟谁走出小屋 |
| 5.2 | Season 归档 | 故事层 | 把 7 天的关键事件汇总成故事线 |
| 5.3 | 个人恋综海报生成 | 前端 | 图片形式的战绩，可分享 |

## 四、时间预估（粗）

| 里程碑 | 估计工时 | 关键难点 |
|---|---|---|
| 1. 单人聊天 | 3-5 天 | 后端搭建 + 人设 prompt 调优 |
| 2. Scene 循环 | 5-7 天 | 结构化输出（JSON）+ 关系更新逻辑 |
| 3. 多人系统 | 4-6 天 | 10 个人的 prompt 分别调 |
| 4. 世界运行 | 5-7 天 | 定时任务 + 事件生成逻辑 |
| 5. Season 结局 | 3-4 天 | 相对简单，主要是汇总 |
| **合计** | **20-30 天** | |
