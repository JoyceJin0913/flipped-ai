```

```

| 天数 | 事件主题 | 弧线阶段 | 核心冲突 | 情感关键词 | 紧张度 |
|------|---------|---------|---------|-----------|--------|
| **Day 1** | 早餐桌上的沉默 | icebreak | 尴尬的初次集体相处 | 观察、第一印象、试探 | 🟢 低 |
| **Day 2** | 分组厨艺大比拼 | icebreak→tension | 团队合作中的分歧与默契 | 竞争、配合、意外发现 | 🟡 中 |
| **Day 3** | 真心话大冒险 | tension | 秘密暴露的边缘 | 脆弱性、试探底线、意外告白种子 | 🟠 中高 |
| **Day 4** | 海边双人约会 | tension | 暧昧升级 + 嫉妒种子 | 独处、心动瞬间、第三方视角 | 🟠 中高 |
| **Day 5** | 天台夜谈·秘密 | climax | 关系摊牌压力测试 | 选择、暴露、真心话 | 🔴 高 |
| **Day 6** | 约会邀请权争夺 | climax | 公开表态、冒险决策 | 承诺、勇气、输赢 | 🔴 高 |
| **Day 7** | 离别前夜·篝火 | resolution | 最终抉择、告别或告白 | 收束、遗憾、决心 | 🟡→🔴 |

### 设计原则

1. **递进式情感升温**：Day 1-2 以破冰为主，Day 3-4 注入暗流，Day 5-6 到达高潮，Day 7 收束
2. **每位 NPC 每天都有发言机会**：8 位 NPC（5 候选 + 3 竞争者）在每次公共事件中均有差异化台词
3. **依恋类型 × 冰山人格交叉体现**：同一种依恋类型在不同 NPC 身上表现不同（如林一和宋清都是 avoidant，但林一是"沉默观察型"、宋清是"理性分析型"）
4. **玩家选择有真实权重**：每个选项对不同 NPC 产生不同 Δ 值，没有"万能最优解"
5. **公共事件 → 私聊链路通畅**：每天事件的 `chatContext` 明确传递给当晚私聊系统

### Day 1 · 早餐桌上的沉默

#### 基本信息

| 属性 | 值 |
|------|---|
| **事件 ID** | `day1_breakfast` |
| **时间** | 10:00 |
| **地点** | 小屋开放式厨房 + 岛台 |
| **弧线阶段** | icebreak（破冰期） |
| **氛围描述** | 晨光微晃，咖啡香气还没散去。八个人围坐在岛台两侧——有人在看手机，有人在倒水，空气里有一种"不知道该说什么"的微妙安静。冰箱压缩机偶尔发出嗡嗡声，像是替所有人尴尬地清了清嗓子。 |

#### 开场旁白

```
这是你们来到心动岛的第一个早晨。
没有导演喊 action，没有剧本提示，
只有阳光透过百叶窗在地板上画出的条纹。

你走进厨房的时候——
七双眼睛，几乎同时看了过来。
有期待的、有戒备的、有假装不在意的。

没有人先说话。
```

#### 触发事件

**周叙**（安全型·ISFJ）自然地打破了沉默：*"大家想吃什么？我来做。"*

---

#### NPC 依次发言（按出场顺序）

##### ① 周叙 ISFJ · secure — 打破沉默的人

> **人格映射**：L1 温柔会照顾人 → L2 大管家定位 → 主动破冰但不过分张扬

```
（挽起袖子，自然地打开冰箱，像是在自己家一样）

"大家想吃什么？我来做。"

（目光温和地扫过每个人，在你这里多停了半秒）

"对了，你对什么过敏吗？"
```

**Δ 好感影响**：**+3**（secure 型主动释放善意，全屋好感基础分）

---

##### ② 林一 INTJ · avoidant — 沉默的观察者

> **人格映射**：L1 话少观察力强 → L2 倾听者定位 → 用沉默保护自己

```
（低头看着手里的咖啡杯，像是在研究里面的漩涡）

"...随便。"

（余光扫了你一下，又迅速移开。手指无意识地摩挲着杯沿）

"……"
```

**Δ 好感影响**：**+1**（avoidant 型最低限度参与，不扣分已是正面信号）

💡 **隐藏线索**：他把你放好的餐具悄悄摆正了一次——左撇子的习惯。如果你注意到了，后续私聊可解锁 L1 表现层线索。

---

##### ③ 沈知 ENTP · anxious — 用幽默破冰

> **人格映射**：L1 反应快爱辩论 → L2 话题发起者 → 用聪明掩饰紧张

```
（靠在门框上，双手抱胸，嘴角带着若有若无的笑）

"哇哦，第一天就有人抢着当管家？周叙你这是要竞选小屋CEO啊。"

（转向你，眼神里带着一丝打量）

"那你呢？你会做饭吗？还是只会——"

（故意停顿了一下）

"——吃？"
```

**Δ 好感影响**：**+2**（anxious 型通过引起你注意力来确认存在感）

---

##### ④ 陆野 ESFP · secure — 气氛组上线

> **人格映射**：L1 阳光精力旺盛直来直去 → L2 气氛组定位 → 完全不设防

```
（从沙发上弹起来，声音比刚才大了两倍）

"做吃的！我饿死了！周叙哥做什么我都行！"

（凑到岛台边，顺手拿起一个苹果咬了一口）

"哎对了，昨天谁说会做那个什么……意式烘蛋来着？不会是我吧哈哈哈"
```

**Δ 好感影响**：**+2**（secure 型天然感染力，拉高全屋能量）

---

##### ⑤ 江郁 INFP · anxious — 安静的存在

> **人格映射**：L1 敏感有艺术气质温柔 → L2 文艺担当 → 在角落观察但不冷漠

```
（站在窗边给窗台上的多肉浇水，动作很轻）

"我……可以帮忙摆盘子。"

（声音不大，但每个人都听到了。转头看向你的时候笑了笑）

"第一次和大家一起吃早餐呢。感觉有点……紧张又期待。"
```

**Δ 好感影响**：**+2**（anxious 型坦诚脆弱，容易引发保护欲）

---

##### ⑥ 顾言 ESTJ · secure — 自然的领导者

> **人格映射**：L1 成熟稳重有规划 → L2 主心骨定位 → 不动声色地掌控局面

```
（从平板电脑上抬起头，语气平稳）

"冰箱里有什么食材？我来列个清单，免得浪费。"

（扫了一眼屋里的人，目光在你身上停留了一瞬）

"第一天，大家放松就好。不用刻意表现什么。"
```

**Δ 好感影响**：**+2**（secure 型提供安全感，降低社交压力）

---

##### ⑦ 程逸 ENFP · secure — 不按常理出牌

> **人格映射**：L1 跳脱点子多自来熟 → L2 惊喜制造者 → 用跳跃思维打破僵局

```
（突然从沙发后面探出头，像是已经在那儿蹲了很久）

"我有个提议！"

（竖起一根手指，表情认真得过分）

"我们每人做一道代表自己的菜！然后盲评！输了的人负责洗一周的碗！"

（看到大家的反应后立刻补了一句）

"……开玩笑的。但我真的想做一道菜。叫'程逸的惊喜'。"
```

**Δ 好感影响**：**+2**（secure 型用幽默化解尴尬，全场轻松）

---

##### ⑧ 宋清 ISTJ · avoidant — 低调靠谱

> **人格映射**：L1 冷静逻辑强有条理 → L2 问题解决者 → 用行动代替语言

```
（已经默默地把咖啡机打开了，正在读说明书）

"咖啡机需要三分钟预热。"

（抬头看了看大家，语气平淡）

"我查过了，冰箱里有鸡蛋、面包、牛奶、还有一点培根。够做简单的早餐。"

（没有看你，但你注意到他把最靠近你的那把椅子往外拉了一点——给你留了更多空间）
```

**Δ 好感影响**：**+1**（avoidant 型通过细微行动表达关心，不邀功）

#### 玩家决策点

**场景**：周叙在厨房忙碌，其他人各自找位置坐下或站着。你需要决定自己在第一个集体场景中的姿态。

| 选项 | 文案 | 设计意图 |
|------|------|---------|
| **A** | "我来帮忙打下手吧" | 主动参与型 —— 展示能力和善意 |
| **B** | "我都行，听大家的安排" | 观察适应型 —— 不给人压力，暗中观察 |
| **C** | "其实我会做[某道菜]……如果需要的话" | 惊喜展示型 —— 适度展示但不张扬 |

#### 好感值影响矩阵（Δ 值）

| NPC | A: 主动帮忙 | B: 听安排 | C: 展示技能 | NPC 反应逻辑 |
|-----|-----------|---------|-----------|------------|
| **周叙** (secure) | **+4** | +1 | **+5** | 安全型欣赏主动和有能力的人，C选项最高（展示能力+给他面子） |
| **林一** (avoidant) | +1 | **+3** | +2 | 回避型喜欢不给人压力的人，B选项让他感到安全 |
| **沈知** (anxious) | **+3** | 0 | +2 | 焦虑型觉得主动的人有趣，想和你互动 |
| **陆野** (secure) | **+4** | +2 | **+4** | 安全型阳光少年，任何互动都加分 |
| **江郁** (anxious) | **+3** | **+3** | +2 | 焦虑型敏感，A和B都能让她感到被接纳 |
| **顾言** (secure) | **+3** | +2 | **+4** | 安全型成熟男，欣赏能力+稳重并存 |
| **程逸** (secure) | **+3** | +1 | **+5** | 安全型ENFP最爱惊喜，C选项直接戳中 |
| **宋清** (avoidant) | +2 | **+3** | +1 | 回避型理性派，B选项最符合他的逻辑 |

### Day 2 · 分组厨艺大比拼

#### 基本信息

| 属性 | 值 |
|------|---|
| **事件 ID** | `day2_cooking_contest` |
| **时间** | 15:00 |
| **地点** | 小屋厨房 + 餐厅区域 |
| **弧线阶段** | icebreak → tension（破冰转暗流） |
| **氛围描述** | 昨天的早餐让大家稍微熟悉了一些，但"熟悉"和"亲近"之间还差着一整个上午的距离。节目组突然宣布下午有分组厨艺比拼——两个人一组，用固定食材做出一道菜。分组方式？抽签。 |

#### 开场旁白

```
午后的阳光斜照进餐厅，
节目组的工作人员搬进来几个巨大的食材箱。

"各位，下午的活动是——分组厨艺挑战。"
工作人员的声音没有任何感情色彩。
"两人一组，抽签决定队友。限时一小时。
评委是——你们自己。"

你看到了几微妙的表情变化。
有人跃跃欲试，有人微微皱眉。
分组意味着合作，也意味着——
有人会被剩下。
```

#### 抽签结果（固定剧本）

| 组别 | 成员 | 化学反应预设 |
|------|------|------------|
| A 组 | 周叙 × 江郁 | 温柔互补组——一个照顾人一个细腻 |
| B 组 | 沈知 × 程逸 | 灾难创意组——两个脑洞王 |
| C 组 | 陆野 × 宋清 | 反差萌组——一个 chaotic 一个 orderly |
| D 组 | 林一 × **你** | 静默默契组——？？ |
| **轮空** | **顾言** | 当评委/自由人（他主动提的） |

##### 比赛过程中 —— 各组动态

**A 组：周叙 × 江郁**

```
【周叙】
（系着围裙，一边切菜一边指导）

"刀这样握会更省力。对，就是这样……
你切的洋葱很均匀，比我细致多了。"

```

"沈知！我觉得我们应该做一个——
'量子力学风格'的分子料理！"

【沈知】
（扶额，深呼吸）

#### 开场旁白

```
瓶身旋转的声音在地毯上格外清晰。
所有人的眼睛都跟着它转。
停下了。

指向了——
```

#### 游戏机制

- 共 **3 轮**，每轮随机选中一人回答问题
- 问题分为三个等级：🟢 轻松 / 🟡 深入 / 🔴 敏感
- 玩家每轮可以选择 **回答 / 跳过 / 反问**
- 不同选择影响不同 NPC 的好感度

---

#### 第一轮：🟢 轻松开场

**被选中：陆野 ESFP · secure**

**问题**："你最近一次心动是什么时候？"

```
【陆野】

"最近一次？呃……"

（偷偷瞄了一眼屋子里的某个人，很快收回视线）

"就……前几天吧。遇到一个觉得挺有意思的人。"

（立刻大声补充）

"但我不告诉你们是谁！这是隐私！下一个！快点转瓶子！"
```
**Δ 影响**：如果他看的人是你 → **+3**；否则 **+1**

**玩家的选择**：

| 选项 | 文案 | 影响 |
|------|------|------|
| **A** | "这么神秘？那我猜猜——" | 陆野 **+2**（你追着他问），沈知 **+1**（觉得你有意思） |
| **B** | 笑而不语，看他怎么圆场 | 陆野 **+1**（你不给他压力），林一 **+1**（同类气场） |
| **C** | "我也很好奇，但尊重隐私啦" | 江郁 **+2**（温柔理解），周叙 **+1**（成熟应对） |

### 3.1 公共事件 Δ 值范围

## 四、公共事件 → 私聊数据传递规范

### 4.1 chatContext 接口定义

```typescript
interface PublicEventChatContext {
  /** 当天事件的话题关键词 */
  topic: string;

  /** 事件中有突出表现的 NPC ID 列表 */
  mentionedNpcs: string[];

  /** 玩家在事件中的立场/行为摘要 */
  playerStance: string;

  /** 事件紧张程度：决定私聊开场氛围 */
  tensionLevel: "low" | "medium" | "high" | "very-high";

  /** 当天值得回顾的关键瞬间（用于生成私聊选项） */
  keyMoments: string[];

  /** 是否触发了关系质变 */
  relationshipTurningPoint?: boolean;

  /** 私聊开场白参考（按 NPC ID 索引） */
  privateChatOpening?: Record<string, string>;

  /** 明日预告（可选） */
  tomorrowPreview?: string;

  /** 嫉妒机制：未被选中的焦虑型 NPC 列表 */
  jealousyTriggered?: string[];
}
```

### 4.2 私聊系统读取方式

```typescript
// 在 ChatSheet 组件打开时
const todayContext = useGameStore(s => s.todayEventContext);

// 传入选项生成引擎
const choices = generateChatChoices({
  eventScript: todayContext,
  npc: currentNpc,
  relationship: currentRelationship,
  playerProfile: profile,
});
```

### 4.3 选项生成的优先级规则

```
优先级 1（最高）：引用当天 keyMoments 中该 NPC 相关的内容
  例：Day 2 "林一主动问你切菜经验" → "其实那天你问我切菜的事……"

优先级 2：结合当天 topic 和该 NPC 的冰山人格
  例：Day 4 "海边" + 江郁 L2 "文艺担当" → "今天海边的风很适合写生吧"

优先级 3：根据 relationship.stage 的阶段保底话题
  例：stranger → "你是做什么工作的？"
      crush  → "我不想只做朋友了"

优先级 4（保底）：随机选取安全模板池选项
```
